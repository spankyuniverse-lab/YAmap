# Запуск из PyCharm

В репозитории лежат готовые конфигурации запуска — открыл проект, выбрал в
списке сверху, нажал ▶. Ничего вбивать руками не надо.

## Первый раз

1. **Открой проект.** PyCharm → `File → Open` → папка `YAmap`.
   (Или `Get from VCS` → `https://github.com/spankyuniverse-lab/YAmap.git`,
   ветка `claude/yandex-maps-kz-parser-s39rcl`.)

2. **Поставь окружение.** В PyCharm внизу вкладка **Terminal**:

   ```bash
   chmod +x setup_mac.sh && ./setup_mac.sh
   ```

   Скрипт создаст `.venv` и поставит зависимости. Нужен Python 3.10+
   (`brew install python@3.12`, если системный старый).

3. **Укажи интерпретатор.** `Settings → Project: YAmap → Python Interpreter`
   → шестерёнка → `Add Local Interpreter…` → **Existing** → выбери:

   ```
   <папка проекта>/.venv/bin/python
   ```

   PyCharm может предложить это сам сразу после `setup_mac.sh` — тогда просто
   согласись.

4. **Перезапусти PyCharm**, если конфигурации не появились в списке.

## Меню (конфигурация 1)

Запуск без аргументов открывает пошаговый опрос. Первый пункт — быстрый путь
для GT:

```
  1. GT по всем городам КЗ (АЗС / продуктовые) ⭐
  2. Поиск по запросу
  3. Парсинг по категориям (как 2ГИС)
  ...
  6. Диагностика: что уже собрано, ошибки, капчи
```

Выбрал `1` → спросит, что собирать (весь GT / только заправки / только
магазины / только еда) и сколько браузеров → покажет сводку → поехали.
Города, собранные в прошлый раз, пропустит.

## Долгие прогоны

Конфигурации 1, 3 и 4 идут часами. Пока они работают:

- **вкладку Run не закрывай** — остановка вкладки убивает сбор
  (прогресс сохранится, но продолжать придётся вручную);
- **окна Chrome не закрывай**;
- **сон мак держит сам** — парсер поднимает `caffeinate` на время прогона,
  независимо от того, откуда запущен. Но **закрытая крышка усыпляет мак в
  обход этого**: держи открытой и ноут в розетке;
- если хочется ещё и авто-перезапуск при падении — запускай из вкладки
  Terminal:

  ```bash
  ./watch_gt.sh --all-cities --category gt-grocery -o kz_grocery.xlsx --workers 2 --api-intercept
  ```

  Так надёжнее: сторож ещё и перезапустит всё, если упадёт целиком.

## Остановка и продолжение

Красный квадрат ⏹ в PyCharm — прогресс сохраняется. Запустишь ту же
конфигурацию снова — продолжит с непройденного города, а не с нуля.

## Где результат

Файлы `.xlsx` появляются в корне проекта (обнови дерево: правый клик по папке →
`Reload from Disk`). Двойной клик — PyCharm покажет таблицу, либо открой в
Numbers/Excel.

Логи — `logs/`, сводки прогонов — `reports/`.

## Если что-то не так

| Симптом | Что делать |
|---|---|
| Конфигураций нет в списке | Перезапусти PyCharm; проверь, что открыта папка `YAmap`, а не родительская |
| `No Python interpreter configured` | Шаг 3 выше — указать `.venv/bin/python` |
| `ModuleNotFoundError: patchright` | Выбран не тот интерпретатор (системный вместо `.venv`) |
| Не запускается — жалуется на путь | Проверь `Working directory` в конфигурации: должно быть `$PROJECT_DIR$` |
| Всё непонятно | Запусти конфигурацию **8. Диагностика** и пришли её вывод |
