# YAmap — Парсер Яндекс.Карт

Парсер организаций с Яндекс.Карт с поддержкой динамической подгрузки результатов (infinite scroll).

## Установка

```bash
pip install -r requirements.txt
playwright install chromium
```

## Использование

```bash
# Базовый запуск
python yandex_parser.py "кофейни Москва"

# С ограничением количества и выводом в CSV
python yandex_parser.py "автосервис Казань" --max-results 200 --output авто.csv

# С открытием карточек для телефонов/сайтов (медленнее)
python yandex_parser.py "рестораны Санкт-Петербург" --detail

# С видимым браузером (для отладки)
python yandex_parser.py "аптеки Новосибирск" --no-headless
```

## Параметры

| Параметр | Описание |
|---|---|
| `query` | Поисковый запрос |
| `--max-results, -n` | Максимум организаций (по умолчанию 500) |
| `--output, -o` | Файл результатов: `.xlsx` или `.csv` (по умолчанию `results.xlsx`) |
| `--detail` | Открывать карточку каждой организации для сбора телефона и сайта |
| `--no-headless` | Показывать браузер |
| `--scroll-pause` | Пауза между прокрутками в секундах (по умолчанию 1.0) |

## Собираемые данные

- Название
- Адрес
- Телефон (с `--detail`)
- Сайт (с `--detail`)
- Рейтинг
- Количество отзывов
- Категория
- Часы работы
- Ссылка на Яндекс.Карты
