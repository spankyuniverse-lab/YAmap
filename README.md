# YAmap — Парсер Яндекс.Карт

Парсер организаций с Яндекс.Карт с поддержкой динамической подгрузки (infinite scroll) и парсинга по категориям (аналог 2ГИС).

## Установка

```bash
pip install -r requirements.txt
playwright install chromium
```

## Использование

### По поисковому запросу

```bash
python yandex_parser.py "кофейни Москва"
python yandex_parser.py "автосервис Казань" -n 200 -o авто.csv
python yandex_parser.py "аптеки Москва" --api-intercept
python yandex_parser.py "рестораны СПб" --detail
```

### По категориям (аналог 2ГИС)

```bash
# Посмотреть каталог категорий
python yandex_parser.py --list-categories

# Все подкатегории группы «еда» (рестораны, кафе, бары, пиццерии, ...)
python yandex_parser.py --city Москва --category еда

# Конкретные категории
python yandex_parser.py --city Москва --category рестораны кафе бары

# Несколько групп + отдельные категории
python yandex_parser.py --city СПб --category авто красота шиномонтаж

# Все категории каталога сразу
python yandex_parser.py --city Казань --all-categories -n 100

# С API-перехватом и обогащением карточек
python yandex_parser.py --city Москва --category здоровье --api-intercept --detail
```

Результат по категориям сохраняется в Excel:
- **Лист «Все результаты»** — сводная таблица с колонкой «Поисковый запрос»
- **Отдельный лист на каждую категорию** (рестораны, кафе, бары, …)

## Параметры

| Параметр | Описание |
|---|---|
| `query` | Поисковый запрос (режим одиночного поиска) |
| `--city` | Город для парсинга по категориям |
| `--category` | Категории или группы (еда, авто, рестораны, кафе, …) |
| `--all-categories` | Парсить все категории из каталога |
| `--list-categories` | Показать каталог категорий и выйти |
| `-n, --max-results` | Максимум организаций на запрос/категорию (по умолчанию 500) |
| `-o, --output` | Файл: `.xlsx` или `.csv` |
| `--api-intercept` | Перехватывать JSON из внутреннего API (надёжнее DOM) |
| `--detail` | Открывать карточку каждой организации для телефона/сайта |
| `--no-headless` | Показывать браузер |
| `--scroll-pause` | Пауза между прокрутками, сек (по умолчанию 1.0) |

## Собираемые данные

- Название
- Адрес
- Телефон (с `--detail` или `--api-intercept`)
- Сайт (с `--detail` или `--api-intercept`)
- Рейтинг
- Количество отзывов
- Категория
- Часы работы
- Поисковый запрос (в режиме категорий)
- Ссылка на Яндекс.Карты

## Режимы сбора данных

### DOM-парсинг (по умолчанию)
Скроллит панель результатов, парсит HTML-сниппеты. Использует устойчивые селекторы `[class*="..."]` для защиты от обфускации классов Яндексом.

### API-перехват (`--api-intercept`)
Перехватывает XHR-ответы внутреннего API Яндекс.Карт при скролле. Данные приходят в JSON — надёжнее и полнее, чем DOM-парсинг.
