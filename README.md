# YAmap — Парсер Яндекс.Карт

Парсер организаций с Яндекс.Карт с поддержкой динамической подгрузки (infinite scroll).

## Установка

```bash
pip install -r requirements.txt
playwright install chromium
```

## Использование

```bash
# Базовый запуск — DOM-парсинг + скролл
python yandex_parser.py "кофейни Москва"

# Ограничить количество, сохранить в CSV
python yandex_parser.py "автосервис Казань" -n 200 -o авто.csv

# Режим перехвата API (надёжнее, данные из JSON)
python yandex_parser.py "аптеки Москва" --api-intercept

# С открытием карточек для телефонов/сайтов
python yandex_parser.py "рестораны СПб" --detail

# Видимый браузер для отладки
python yandex_parser.py "аптеки Новосибирск" --no-headless

# Комбинация: API + детальные карточки
python yandex_parser.py "стоматологии Москва" --api-intercept --detail -n 100
```

## Параметры

| Параметр | Описание |
|---|---|
| `query` | Поисковый запрос |
| `-n, --max-results` | Максимум организаций (по умолчанию 500) |
| `-o, --output` | Файл: `.xlsx` или `.csv` (по умолчанию `results.xlsx`) |
| `--api-intercept` | Перехватывать JSON из внутреннего API (надёжнее DOM) |
| `--detail` | Открывать карточку каждой организации для телефона/сайта |
| `--no-headless` | Показывать браузер |
| `--scroll-pause` | Пауза между прокрутками, сек (по умолчанию 1.0) |

## Два режима работы

### DOM-парсинг (по умолчанию)
Скроллит панель результатов, парсит HTML-сниппеты. Использует устойчивые селекторы `[class*="..."]` для защиты от обфускации классов Яндексом.

### API-перехват (`--api-intercept`)
Перехватывает XHR-ответы внутреннего API Яндекс.Карт при скролле. Данные приходят в JSON — надёжнее и полнее, чем DOM-парсинг.

## Собираемые данные

- Название
- Адрес
- Телефон (с `--detail` или `--api-intercept`)
- Сайт (с `--detail` или `--api-intercept`)
- Рейтинг
- Количество отзывов
- Категория
- Часы работы
- Ссылка на Яндекс.Карты

## Селекторы

Парсер использует CSS-селекторы с поиском по подстроке (`[class*="..."]`), что устойчиво к периодическому добавлению числовых префиксов в классы Яндекс.Карт. Селекторы верифицированы по нескольким открытым парсерам.

При изменении структуры DOM все селекторы собраны в начале `yandex_parser.py` для удобного обновления.
